1. What is Full Stack Development?

Full stack development is the practice of building both the front-end (client-side) and the back-end (server-side) of a web application, along with the database that stores its data.

The Layers of the Stack
  • Front-End: HTML, CSS, Bootstrap, JavaScript, React
  • Back-End: Node.js, Python, PHP, Java
  • Database: MySQL, PostgreSQL, MongoDB
  • DevOps: Git, Docker, AWS, CI/CD

3. CSS (Cascading Style Sheets)

CSS controls the presentation of HTML — colours, fonts, layout, and 3D transforms.

Key Concepts Demonstrated
  • Selectors: element, class, ID
  • Box Model: margin, border, padding
  • Flexbox & Grid: modern layout
  • Pseudo-classes: :hover, :focus
  • Transitions & Animations
  • 3D Transforms: rotateY, perspective
  • RGB & Gradient colours
